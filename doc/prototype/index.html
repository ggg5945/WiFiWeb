架构前后端分离：FastAPI 提供 REST API（JSON），前端为独立静态页面（原生 JS 单页，无构建步骤），由后端静态托管
无线操作原生 WLAN API（wlanapi.dll，ctypes 调用）+ netsh wlan 兜底，无第三方依赖
多网卡支持多张无线网卡的选择/切换（顶栏网卡胶囊），选择持久化到 app.properties；配置文件严格跟随所选适配器（Windows 按适配器分开存储）
访问控制局域网内均可访问，无登录口令；应用自身仅用 app.properties 保存选中网卡与自动刷新配置（无数据库），已保存网络由 Windows WLAN 配置文件按适配器管理
端口8086
隐藏网络支持"手动添加网络"入口：直接输入 SSID + 密码（密码留空视为开放网络）
扫描列表频段列（2.4 GHz / 5 GHz / 6 GHz），支持按 SSID 包含 / 频段 / BSSID 包含筛选
自动刷新OpenWrt 式自动刷新：开关 + 间隔可调（3~600 秒），后端定时扫描并缓存，倒计时后端下发；无客户端心跳时自动停扫
启动方式不做开机自启/服务，提供启动脚本（start.bat，自动提权并写入扫描位置策略旁路键）
页面结构（3 个功能页签；原型额外含「原型说明」）

顶栏显示页面标题、⇄ 当前无线网卡（点击弹出选择窗，支持取消 / ESC 关闭）与全局连接状态；左侧为菜单（概览 / 扫描并加入网络 / 已保存网络），手机窄屏时菜单收纳为抽屉（☰ 展开）；页面通过 URL hash 记忆当前页签：

  • 概览 —— 当前无线状态 + 刷新状态 / 切换无线网卡 / 断开连接
  • 扫描并加入网络 —— 顶部：重新扫描 | 自动刷新开关 + 间隔 + 倒计时 | 筛选（SSID 包含 / 频段 / BSSID 包含）| 手动添加网络；表格：信号|SSID|频段|信道|模式|BSSID|加密|加入
  • 已保存网络 —— 当前网卡上的已保存配置：连接 / 自动连接开关 / 忘记；切换网卡后自动刷新
1. 概览
当前连接卡片：接口名、SSID、BSSID、信号强度（图标 + dBm + 链路质量%）、信道/频段、加密方式、IPv4、IPv6；系统"定位服务"关闭导致部分信息被系统隐藏时有明确提示。
「刷新状态」重新读取当前无线接口状态；「切换无线网卡」入口在顶栏网卡胶囊；「断开连接」弹出二次确认，断开后切换为"未连接"空态，提供"去扫描网络"入口。
左下角演示开关仅原型用，可切换"已连接 / 未连接"两种状态演示。
2. 扫描并加入网络（对标 openwrt WiFi 桥接扫描界面）
顶部工具栏（在表格上方）：🔄 重新扫描 / 自动刷新开关 + 间隔（3~600 秒）+ 倒计时 / 筛选（SSID 包含 / 频段 / BSSID 包含） / ➕ 手动添加网络（原型演示中简化为"停止刷新"按钮）。
表格列：信号 | SSID | 频段 | 信道 | 模式 | BSSID | 加密 | 操作；信号列 = 信号条图标 + dBm（含链路质量%），按信号强度降序排列；列表增量更新不闪烁。
同名 SSID 多 BSSID（Mesh）时按 BSSID 展开为多行；隐藏网络显示为"隐藏"（斜体），加入时需手动输入 SSID；扫描中（含切换网卡后首次进入）显示 spinner 占位行。
「加入网络」弹窗：加密网络需输入密码（可切换明文，<8 位禁用按钮）；开放网络无需密码并显示明文传输警告；隐藏网络额外出现 SSID 输入框；"保存此网络并自动连接"默认勾选；新配置只保存到当前选中的无线网卡。
「手动添加网络」使用同一弹窗：手动输入 SSID + 密码，密码留空视为开放网络。
连接进度弹窗：转圈 + "正在连接到 XXX"；成功后"完成"跳回概览；失败显示失败原因，可"修改密码重试"或"关闭"（原型演示中密码输入 12345678 可模拟失败）。
3. 已保存网络
仅显示当前选中无线网卡上保存的配置（Windows 的 WLAN 配置文件按适配器分开存储，其他网卡保存的网络不会显示在这里）：SSID（当前连接带绿色标记）、加密、自动连接开关、状态、操作（连接 / 忘记，忘记需二次确认并只删除当前网卡上的配置）。
切换网卡后列表自动刷新；当前网卡无保存网络时显示说明提示；底部「➕ 添加新网络（扫描）」跳转扫描页签。
